# CAD LISP Utilities

This repository contains two AutoLISP commands for working with drawing text:

- **TextCase.lsp** changes the letter case of selected text objects.
- **TXT2ML.lsp** combines selected text objects into one multileader.

## Loading

In AutoCAD, load the desired `.lsp` file with **APPLOAD**. After loading, run
its command from the command line:

- `TC` for TextCase
- `TXT2ML` for TXT2ML
